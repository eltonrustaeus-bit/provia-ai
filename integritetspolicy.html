Vad vi samlar in

ExGen samlar in minimal data för att kunna erbjuda tjänsten. Vi använder inga spårningscookies, inga annonsnätverk och inga tredjepartsanalysverktyg.

  • Kontoinformation: e-postadress och lösenord (hashad) vid registrering. Lagras i Supabase (EU-region).
  • Studieprogress: dina provresultat, felbanken och kategoriframsteg. Lagras i Supabase kopplat till ditt konto.
  • Profil och anpassning: om du fyller i P.E.R:s introduktion kan uppgifter som skolform, årskurs, program, skola, ämnen, mål, provdatum och önskat hjälpsätt sparas på ditt konto. P.E.R kan också spara sammanfattade studiesignaler från användningen.
  • P.E.R-samtal: upp till 40 meddelanden i den senaste chatthistoriken samt ett separat långtidsminne kan sparas på ditt konto för att anpassa hjälpen. Du kan granska och ta bort profiluppgifter samt rensa P.E.R-minnet under Konto. Långtidsminnet markeras som inaktuellt efter 90 dagar och tas bort när det därefter läses in.
  • Innehåll du skickar till AI: beroende på funktion kan studiematerial, frågor, svar, text från uppladdade bilder och relevanta studiesignaler behandlas av OpenAI för att skapa prov, rätta svar, läsa text eller ge hjälp. Lärarens klassinsikt körs först när minst fem elever har provdata. AI:n får då antal elever, klassens genomsnitt avrundat till närmaste tiotal procent och begrepp som återkommer hos minst tre elever, med antal. Inga elevvisa rader, namn, e-postadresser eller klassnamn skickas. Aggregat kan fortfarande vara personuppgifter och kräver skolans godkända upplägg.
  • Lokalt på din enhet: inloggningssession, sparad provhistorik, felbank, material och väntande svar samt cachade AI-förklaringar. Om ett rättat prov inte kan sparas till kontot behålls en reservkopia med prov, svar och resultat i en lokal kö avgränsad till det inloggade kontot, tills sparningen lyckas eller du rensar lokal data. Se tabellen nedan.

Cookies & lokal lagring

Vi använder localStorage (webbläsarlagring, inte traditionella cookies) för session, provdata och inställningar. Uppgifterna finns kvar tills de rensas av ExGen eller webbläsardata tas bort. Att rensa webbläsaren raderar inte automatiskt uppgifter som sparats på kontot. Inga data delas med tredje part för marknadsföring.

Tredjepartstjänster

  • Supabase (databas & auth) — EU-region (Frankfurt). Supabase integritetspolicy
  • OpenAI (AI-funktioner) — innehåll som behövs för den funktion du använder kan skickas för att skapa prov, rätta eller förklara svar, läsa bildtext och skapa lärarstöd. Skicka inte känsliga personuppgifter i studiematerial eller chattar. OpenAI integritetspolicy
  • Resend (transaktionsmejl) — e-postadress och uppgifter som behövs för välkomst- och kontomejl skickas för leverans. Registreringsaviseringar med elevens e-post eller konto-ID skickas inte till en separat administratörsmail.
  • Stripe (betalning) — om du uppgraderar. Kortuppgifter hanteras enbart av Stripe. Stripe integritetspolicy
  • Vercel (hosting) — serverloggar inkl. IP-adress (ingen spårning). Vercel integritetspolicy
  • Google Fonts — typsnitt laddas från Google. Google integritetspolicy

Dina rättigheter (GDPR)

Du har rätt att begära ut, rätta eller radera dina uppgifter. Kontakta oss på elton.rustaeus@gmail.com så hjälper vi dig.

Uppgifter i P.E.R:s profil och minne kan hanteras från Konto. Radering av profil eller minne tar inte automatiskt bort sparade provresultat, som hanteras separat. Förfrågningar om radering av konto eller andra uppgifter görs via kontaktadressen ovan.

Du kan radera all lokal data direkt i din webbläsare via Inställningar → Webbplatsdata → exgen.se.
